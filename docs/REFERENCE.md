# 레퍼런스 데이터 수집 보고서

> 수집일: 2026-10-12 · 도구: [Firecrawl](https://firecrawl.dev) API · 스크립트: [`scripts/crawl.py`](../scripts/crawl.py)

서비스를 만들기 전에 "MBTI 운세는 보통 어떤 항목을, 어떤 길이와 말투로 보여주는가?"를 알기 위해 실제 운세 기사를 수집해 분석했다.
수집한 원문은 저작물이므로 **분석에만 쓰고 저장소에는 올리지 않았다** (`.gitignore`로 `data/` 제외).

## 1. 수집 대상 검토

| 후보 | 결과 | 이유 |
|---|---|---|
| 운세의 신 (unsin.co.kr) 평생사주 | ❌ 제외 | 결과 페이지가 생년월일 입력 + **유료 결제** 후에만 생성됨. 입력 없이 접근하면 빈 틀만 나옴 |
| 비건뉴스 「오늘의 MBTI 운세」 | ✅ 선택 | 무료 공개 기사, 16유형이 일정한 형식으로 정리됨, `#MBTI 운세` 태그로 목록 수집 가능 |

## 2. 수집 방법

1. 태그 목록 페이지(`tag_list_all.html?tag=MBTI 운세&page=N`)를 Firecrawl로 마크다운 변환 → 기사 번호 추출
2. 기사 페이지마다 Firecrawl `scrape` 호출 → 원문 마크다운을 `data/raw/{기사번호}.md`로 캐시 (재실행 시 크레딧 절약)
3. 정규식으로 파싱: 제목, 등록일, 도입 문단, 유형별(ISTJ~ENTJ) 항목
4. `data/mbti_fortune.json`(기사 단위), `data/mbti_fortune.csv`(유형 단위 한 줄씩)으로 저장

```bash
python scripts/crawl.py            # 태그 목록 전체
python scripts/crawl.py --pages 1  # 최근 1페이지만
```

## 4. 서비스에 반영한 점

| 발견 | 반영 |
|---|---|
| 운세는 "한 줄 요약 + 생활 영역별 조언" 구조가 읽기 쉽다 | 한 줄 운세 + 대인관계 / 일·학업 / 생활 리듬 카드 구성 |
| 항목당 35~40자, 한 문장 | 모든 문구를 한 문장, 비슷한 길이로 작성 |
| 점괘보다 **행동 조언형 문장**("~해보자") | 직접 쓴 문구도 같은 톤으로 작성 |
| 기사 하나에 16유형이 길게 나열돼 내 유형 찾기가 불편 | **내 유형만 바로** 보여주는 화면 |

운세 문구(`app/fortunes.json`)는 수집 데이터를 복사하지 않고 **16유형 × 4항목 × 4문구를 직접 작성**했다.
